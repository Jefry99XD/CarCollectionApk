## 📝 NOTAS DE IMPLEMENTACIÓN

### Para logros de **cantidad total** (cualquier carro):
- Concepto: **vacío**
- Campos: NAME (o cualquier otro)
- Tipo: EXACT (no importa aquí)

### Para logros de **filtro específico**:
- Concepto: término a buscar
- Aliases: variaciones del término
- Campos: donde buscar (NAME, BRAND, COLOR, etc.)
- Tipo: EXACT, CONTAINS, o STARTS_WITH

### Para logros de **lista** (lógica OR):
- Lógica: OR
- Una condición por cada elemento de la lista
- Meta = número de elementos en la lista

### Para logros de **combinación** (lógica AND):
- Lógica: AND
- Una condición por cada requisito
- Un carro debe cumplir TODAS las condiciones

### Para logros de **nivel** (USER):
- Categoría: USER
- No requieren condiciones
- Meta = nivel requerido
